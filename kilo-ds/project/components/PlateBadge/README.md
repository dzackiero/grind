# PlateBadge
Personal records drawn as weight plates, coloured like competition bumper plates.

| Distance | Plate | Token |
|---|---|---|
| 1K, 1 mile, 2 mile | change plate | `plate-white` |
| 5K | 10 kg green | `plate-green` |
| 10K | 15 kg yellow | `plate-yellow` |
| Half marathon | 20 kg blue | `plate-blue` |
| Marathon | 25 kg red | `plate-red` |

Strength PRs (estimated 1RM per lift) use the same plate. Locked plates use `surface-raised` with `ink-subtle` text and a goal or "Not yet" line. The rim and inner ring are `plate-rim`, so white plates still read on the light theme.
