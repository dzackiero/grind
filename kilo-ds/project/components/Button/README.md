# Button
Pill buttons; lime is reserved for the one main action on a screen.

- `.k-btn--primary`: lime fill with `on-accent` text. One per screen (Start plan, Log workout, Accept changes).
- `.k-btn--outline`: secondary actions on cards (Manage plan, Rearrange).
- `.k-btn` (default): neutral fill on `surface-raised` for low-stakes actions.
- `.k-btn--ghost`: text link in `accent-ink` (See all, Expand).
- `.k-btn--float`: the bottom "Log workout" button, the only element with `shadow-float`.

Height 44px (56px floating), `radius-pill`. Labels say exactly what happens: "Accept changes", never "OK".
