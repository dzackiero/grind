# WorkoutCard
The main card on Today: one planned workout, its key numbers and a done checkbox.

Put the type class (`t-intervals`, `t-strength`…) on the card; the tag square picks up the colour. No coloured side rail: the type shows through the tag and the label.

- Planned: three metrics (distance or duration, target pace, recovery or sets).
- Completed: metrics come from the matched intervals.icu activity and add an "On target" score in `success`, `warning` or `danger`.
- Strength cards show the duration range (40–50 min) and exercise count instead of pace.

Numbers use the display face with tabular numerals. Paces are always min/km.
