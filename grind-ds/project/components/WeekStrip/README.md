# WeekStrip
Sticky header on Today: plan week, seven days and one dot per planned workout.

- Today: lime filled circle. Days with every workout done: `success` ring.
- Dots use the type `-mark` tokens, three per day at most.
- The ring next to "Week 2 / 12" is plan progress (weeks elapsed over total), in `accent`.
- Tapping a day scrolls Today to that day's workouts.
