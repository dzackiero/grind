# StepList
The structured steps of a run, in the same order as the Huawei workout editor so they can be copied in under a minute.

Each step: name, then duration or distance and target in the mono `data` style. A thin strip on the left takes the step's intensity colour (warm-up and cool-down easy, work steps the session type, recoveries neutral). Repeat blocks get an uppercase "Repeat N times" label and indented steps. After the run, the same list shows actual pace per rep next to the target.
